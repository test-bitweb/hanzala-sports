# Hanzala Sports — website demo

## GitHub Pages-এ চালু করুন
১. `hanzala-sports-demo` নামে একটি Public repository তৈরি করুন।
২. এই ফোল্ডারের ভেতরের সব ফাইল এবং assets ফোল্ডার আপলোড করুন। index.html যেন repository-এর root-এ থাকে। ZIP ফাইল সরাসরি আপলোড করবেন না।
৩. Commit করার পর Settings > Pages > Deploy from a branch > main > /(root) > Save।
৪. ডেপ্লয় শেষ হলে Pages সেটিংসে লাইভ লিংক পাবেন।

Build বা package install লাগবে না। ZIP extract করে index.html খুলেও দেখা যাবে।
পণ্য ও দাম: config.js | লেখা: index.html | ডিজাইন: style.css | ছবি: assets/collection.png

ছবি, দাম ও পণ্য নমুনা। আসল অর্ডার, পেমেন্ট, ইনভেন্টরি বা অ্যাডমিন সিস্টেম নেই। ব্যাগ ও নোট শুধু ব্রাউজারে সংরক্ষিত হয়। ওয়েবসাইটে কোনো ব্যক্তিগত তথ্য জমা দেওয়ার প্রয়োজন নেই।
বিক্রেতার যাচাই করা ছবি, দাম, নীতি ও যোগাযোগের তথ্য বসিয়ে তবেই আসল দোকান হিসেবে ব্যবহার করুন।
